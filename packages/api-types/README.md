# @elido/api-types

TypeScript types for the [Elido](https://elido.app) API, generated from Elido's public OpenAPI spec (<https://elido.app/openapi.json>).
Used by [`@elido/sdk`](../sdk) and usable on its own.

## Install

```bash
npm i @elido/api-types
```

## Usage

```ts
import type { User, Link, Workspace } from "@elido/api-types";
```

The package is types-only (no runtime code).
